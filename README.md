## 🎯 What Is MB_viewer?

MB_viewer is a **free offline desktop application** for instantly previewing, editing, and comparing design files without setting up a development environment.

It began as a fast way to open `.tsx` and `.jsx` files generated by tools like Claude, ChatGPT, Gemini, and other AI coding assistants. Instead of creating a Vite project, installing dependencies, copying code into CodePen, or starting a local dev server, you can simply drag a file into MB_viewer and see it rendered immediately.

Since v2.5.0, MB_viewer has grown into a much broader offline workspace for modern AI-assisted file viewing:

- ⚛️ **TSX / JSX component preview** — instantly render React components without npm, Vite, or project setup
- 🌐 **HTML page preview** — open static pages, mockups, exports, and prototypes in a sandboxed viewer
- 📝 **Professional Markdown reading and editing** — preview docs with tables, code blocks, links, lists, and clean typography
- 📐 **KaTeX math rendering** — display LaTeX-style equations beautifully inside Markdown files
- 🎨 **Mermaid diagram rendering** — view flowcharts, sequence diagrams, ER diagrams, Gantt charts, timelines, mindmaps, and more
- 📊 **Multi-file comparison** — use single, split, or quad view to compare up to four files side by side
- 📑 **Multi-tab workspaces** — keep multiple independent workspaces open in one window
- 🪟 **Multi-window workflows** — drag tabs out into new windows and move tabs between windows
- 🔍 **Advanced search and zoom** — search inside files, highlight matches, and zoom each panel independently
- ✏️ **Live editing with save support** — edit files, preview changes, and save your work directly
- 🌙 **Complete dark mode and themes** — use a 3-layer theme system for the app, code blocks, and editor

MB_viewer has now passed **3500+ downloads**, with strong feedback from developers, designers, technical writers, students, researchers, and AI-assisted builders. Version **3.0.0** is the biggest public step forward so far: from a focused TSX preview tool into a full offline workspace for components, documents, diagrams, math, and multi-file review.

## 🎯 What's New Between 2.5.0 and 3.0.0 (All features)

From v2.5.0 to v3.0.0, MB_viewer evolved from a focused TSX/JSX preview tool into a full offline design-file workspace.

The original v2.5.0 branch already supported instant preview, live editing, advanced search, per-panel zoom, multi-slot selection, and up to four files side by side. The releases after that added professional markdown rendering, offline math, a complete dark mode, Windows file association, tabs, multi-window workflows, cross-window tab dragging, and finally Mermaid diagrams in v3.0.0.

### 🌟 Major Additions Since v2.5.0

#### 🎨 Mermaid Diagrams in Markdown and `.mmd`

MB_viewer v3.0.0 can render Mermaid diagrams directly inside Markdown files and as standalone `.mmd` / `.mermaid` files.

- Sequence diagrams

This makes MB_viewer useful for research notes, technical documentation, model explanations, engineering writeups, academic content, and data-science reports.

MB_viewer continues to support live file editing.

For AI-generated files, this is often faster than moving into a full IDE just to inspect or lightly adjust an output.

## ❓ FAQ

### 💸 Is MB_viewer free?

Yes. MB_viewer is free for personal and commercial use.

### 🔒 Does MB_viewer work offline?

Yes. The core rendering engines are bundled locally. TSX preview, Markdown rendering, KaTeX math, syntax highlighting, and Mermaid diagrams can work offline.

### 🧰 Do I need Node.js?

No. Users downloading the packaged app do not need Node.js, npm, Vite, webpack, or any project setup.

### ✏️ Can I edit files?
